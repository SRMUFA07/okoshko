# Локальный запуск Telegram Mini App по HTTPS

В этом проекте страница Mini App находится на `/app`. Чтобы открыть её с телефона внутри Telegram, мы подняли обратный SSH-туннель через `localhost.run`. Сервис выдаёт временный домен вида `*.app.lhr.life`, принимает HTTPS на своей стороне и передаёт запросы через SSH к Spring Boot на твоём компьютере. Приложение продолжает слушать обычный HTTP, а база остаётся локальной. Для короткого теста сервис даёт домен без регистрации. [Условия localhost.run](https://localhost.run/docs/forever-free)

## Запуск с нуля
1. Запусти приложение

2. В терминале открой туннель.

   ```bash
   ssh -nT -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 \
     -R 80:127.0.0.1:8080 nokey@localhost.run
   ```

   При первом подключении SSH может попросить подтвердить ключ сервера. Сверь отпечаток с [документацией сервиса](https://localhost.run/docs/security). На нашем Mac соединение шло через уже запущенный SOCKS5-прокси на порту `10808`. Если у тебя есть такой прокси и прямое соединение не проходит, добавь перед `nokey@localhost.run` параметр `-o 'ProxyCommand=nc -X 5 -x 127.0.0.1:10808 %h %p'`.
3. Скопируй HTTPS-адрес из строки `tunneled with tls termination`, допиши `/app` и открой результат в браузере. Если страница загрузилась, укажи этот полный URL в кнопке меню тестового бота через `/setmenubutton` в BotFather и открой кнопку в чате с ботом. [Документация Telegram Mini Apps](https://core.telegram.org/bots/webapps#launching-mini-apps-from-the-menu-button)

Оставь Spring Boot и SSH запущенными, пока тестируешь. Адрес публичный, поэтому используй тестовые данные. Если сервис сменил домен, обнови адрес в кнопке. Чтобы закрыть доступ, нажми **Ctrl+C** в терминале с SSH.
