ДЕМО-ФАЙЛ: информация об обработке персональных данных

Это временный макет для проверки сценария Telegram-бота приложения «Окошко».
Он не является юридическим документом и не заменяет утверждённый текст согласия.

Черновое требование к тексту согласия для заявки:
пользователь должен быть уведомлён, что Telegram ID, полученный из проверенных
данных Telegram, связывает заявку и будущий личный кабинет с аккаунтом, из
которого отправлена заявка; на этот аккаунт бот отправляет напоминания, если
пользователь включил их в настройках.

В рабочем приложении здесь должен находиться утверждённый школой документ,
который объясняет, какие персональные данные собираются, для каких целей,
как долго хранятся и как пользователь может отозвать согласие.

Нажатие «Да» в этом демонстрационном сценарии только открывает локальный макет
приложения. Имя, фамилия, телефон и Telegram ID не сохраняются.
