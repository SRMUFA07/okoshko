# Окошко

«Окошко» — сервис, который помогает клиенту попасть к своему мастеру раньше, если освободилась запись, а мастеру — заполнить внезапно появившееся свободное время.

Основной сценарий: клиент выбирает мастера и подходящее время, мастер публикует освободившийся слот, подходящие клиенты получают уведомление, а слот достаётся тому, кто успешно подтвердил запись первым.

> Сейчас в репозитории находится только стартовый backend на Spring Boot. Telegram WebApp, бизнес-сценарии, база данных и интеграция с Telegram ещё не реализованы. Актуальные задачи и их статус — в [PLANS.md](PLANS.md).

## Технологии

- Java 21
- Spring Boot 4.1.1
- Maven Wrapper

## Требования

- JDK 21
- Git

Проверить Java:

```bash
java -version
```

## Запуск

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone <URL репозитория>
cd okoshko
```

Запустите приложение через Maven Wrapper:

```bash
./mvnw spring-boot:run
```

В Windows используйте `mvnw.cmd spring-boot:run`.

Пока приложение — минимальный Spring Boot каркас без HTTP API. Имя приложения задаётся в `src/main/resources/application.properties`.

## Проверки

```bash
./mvnw test
```

Текущий тест проверяет загрузку Spring-контекста; предметных тестов пока нет.

## Структура проекта

```text
src/
  main/java/com/okoshko/     точка входа Spring Boot
  main/resources/            конфигурация приложения
  test/java/com/okoshko/     тесты
```

## Рабочий процесс

1. Перед изменениями прочитайте [AGENTS.md](AGENTS.md) и относящиеся к задаче разделы [PLANS.md](PLANS.md).
2. Реализуйте задачу в рамках согласованного текущего этапа. Если выяснилось, что этап или требования не определены, сначала зафиксируйте это в плане и предложите конкретный вариант.
3. Запускайте проверки, относящиеся к изменению, и указывайте результат в итоговом сообщении.
4. После завершения задачи обновите статус и, если нужно, содержание `PLANS.md` в том же изменении.

## Продуктовый фокус

Первый сквозной сценарий должен доказать, что мастер может опубликовать свободное окно, подходящий клиент получает предложение, а подтверждение не позволяет занять один слот дважды. Не добавляйте дашборды, диаграммы и второстепенные функции до определения и проверки этого потока.
